TechSphere / Experimental Framework

Project Methodology

Technical specifications, crawler implementation, evaluation metrics, and experimental verification.

The primary objective of TechSphere is to provide a controlled, transparent testbed for evaluating web crawler behavior. We assess how automated agents navigate hyperlinked graphs, parse XML sitemaps, eliminate duplicate paths, and comply with the Robots Exclusion Protocol (RFC 9309).

How Crawling and robots.txt Work Together

Search engines and research crawlers follow a systematic 6-stage decision pipeline to balance discovery with site owner rules:

  1. Seed Initialization: The crawler is loaded with starting URLs and initializes a FIFO queue and an empty visited set.
  2. Robots.txt Retrieval: Before requesting any content, the bot fetches and parses /robots.txt at the site root using urllib.robotparser.
  3. Queue Selection: The next candidate URL is popped from the front of the FIFO queue.
  4. Permission Check: The candidate URL is verified against parsed directives for the declared User-agent.
  5. Conditional Fetch: If ALLOWED, the page is fetched via HTTP GET. If BLOCKED, the URL is logged as skipped and immediately discarded.
  6. Link Extraction & Normalization: New hyperlinks are extracted from the HTML, normalized to absolute URIs, checked against the visited set, and enqueued.

Python Implementation Stack

Our educational crawler prototype is built using Python's standard libraries and established open-source data mining packages:

ComponentTechnology / LibraryRole in Experiment
HTTP EnginePython requestsIssues HTTP GET requests with custom User-Agent, politeness delays, and status handling.
DOM ParserBeautifulSoup4 (bs4)Parses HTML DOM trees to extract anchor tags (<a href>) and page titles.
Robots Protocolurllib.robotparserParses root /robots.txt and evaluates Allow / Disallow path expressions.
Queue Managercollections.dequeProvides $O(1)$ time complexity for FIFO push and pop operations during BFS traversal.
Visited SetPython set()Tracks visited URLs in hash table memory for instantaneous duplicate detection.
URL Normalizerurllib.parseResolves relative hyperlinks and strips URL fragments to prevent duplicate indexing.
