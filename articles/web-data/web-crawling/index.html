Introduction to Web Mining

Web mining extracts valuable knowledge from unstructured and semi-structured web data through three fundamental approaches:

1. Web Content Mining

Extracts and analyses useful information from webpage content such as text, images, and multimedia.

2. Web Structure Mining

Discovers and analyses the link structure between web pages to understand graph relationships and hierarchies.

3. Web Usage Mining

Analyses user behaviour, navigation patterns, and access trends using browsing data and HTTP server logs.

Web crawlers serve as the primary discovery mechanism for Web Structure and Content Mining, systematically fetching and indexing web documents for downstream analysis.

Web Crawler Architecture

A web crawler (also called a spider or bot) systematically explores the internet by traversing hyperlinks. The architectural lifecycle follows a continuous pipeline:

  1. Seed Initialization: The crawl begins with a predefined list of seed URLs enqueued into a FIFO queue.
  2. Rule Verification: Before requesting each resource, the crawler parses robots.txt directives to ensure automated visits are permitted.
  3. HTTP Fetching: The crawler issues polite HTTP GET requests, handling status codes, timeouts, and headers.
  4. Content Parsing & Link Extraction: Permitted HTML is parsed, outgoing <a href> hyperlinks are extracted and normalized to absolute URLs.
  5. Duplicate Prevention: Discovered links are checked against a visited set. Unvisited, in-scope URLs return to the FIFO queue.

Breadth-First Search (BFS) Crawling Algorithm

TechSphere implements a Breadth-First Search traversal strategy using a FIFO queue. BFS discovers web pages level by level from the seed URL, preventing deep recursion traps while exploring the website's topological hierarchy evenly.

# Breadth-First Search (BFS) Crawler Pseudocode def crawl(seed_url, max_pages): queue = deque([seed_url]) visited = set() pages_crawled = 0 while queue and pages_crawled < max_pages: url = queue.popleft() # 1. Dequeue FIFO if url in visited: # 2. Skip duplicates continue if not is_allowed_by_robots(url): # 3. Check robots.txt continue html = fetch_page(url) # 4. Fetch HTTP GET if html: visited.add(url) # 5. Mark visited pages_crawled += 1 links = extract_links(html) # 6. Extract links for link in links: if is_valid_same_domain(link): queue.append(link) # 7. Enqueue new links

Level-by-Level Visitation Order:
Level 0 (Start Seed Page) → Level 1 (Direct links: Page A, Page B, Page C) → Level 2 (Sub-pages: Page D, Page E, Page F, Page G, Page H). This guarantees that shallow, authoritative pages are indexed before deep nested resources.
