About TechSphere

An educational web-mining testbed exploring crawler traversal, link topology, and robots.txt compliance.

TechSphere is an academic web-mining research project exploring "How Search Engines Discover and Crawl Web Pages". The platform was created by Yogesh Tanwar, Akshata Sonsurkar, Samiya Shaikh, and Shraddha Pawade as a live demonstration environment.

The testbed is composed of 40 cross-linked educational pages spanning 5 technology domains, structured to evaluate:

  • Hyperlink Traversal: Evaluating Breadth-First Search (BFS) graph discovery using a FIFO queue.
  • Protocol Compliance: Testing compliant parser handling of root robots.txt directives under RFC 9309 standards.
  • Duplicate Detection: Measuring URL canonicalization and visited-hash filtering to prevent crawling cycles.
  • Structured Discovery: Comparing organic hyperlink graph traversal against XML sitemap harvesting.
