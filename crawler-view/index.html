What This Demonstrates (Evaluator's Guide)

1. Breadth-First Traversal (BFS)

The crawler uses a FIFO queue (collections.deque) to exhaust Level 0 (Home), then Level 1 (5 Categories & Utility), then Level 2 (30 Articles). This guarantees shortest hop-count discovery and avoids deep recursion traps.

2. RFC 9309 robots.txt Compliance

Before issuing any HTTP request, the candidate URL is checked against root /robots.txt. Notice that /drafts/ and /internal/ are intercepted and skipped immediately without sending network requests!

3. $O(1)$ Duplicate Elimination

Because every page has a header linking back to /, /about/, and categories, the site contains over 890 link references. The Python hash set (visited = set()) detects duplicate occurrences in $O(1)$ time, preventing infinite loops.

Try the Interactive Test: Uncheck "Obey robots.txt" at the top and hit Run Simulation. You will observe that without robots compliance, the crawler trespasses into /drafts/ and /internal/. Re-checking the box immediately re-enforces the RFC 9309 security boundary!
